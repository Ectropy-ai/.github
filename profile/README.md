# Ectropy

One construction record, keyed the same at every handoff between firms.

## Public repositories

| Repository | What it is | Licence |
|---|---|---|
| [Ectropy-ai/schemas](https://github.com/Ectropy-ai/schemas) | The open standard: JSON Schemas for the records that cross a handoff (decisions, inspections, voxels, jobsite flow, payroll, carbon), served at [schemas.ectropy.ai](https://schemas.ectropy.ai/) | Apache-2.0 |
| [Ectropy-ai/core](https://github.com/Ectropy-ai/core) | TypeScript packages: IFC, federation, clash, row-level security, AI provider, MCP client and SDK | Apache-2.0 |
| [Ectropy-ai/construction-commercial-context](https://github.com/Ectropy-ai/construction-commercial-context) | Types for construction cost, carbon and jurisdiction data | Apache-2.0 |

## What is open

The standard publishes what a record is when it crosses a handoff: its shape, keys, identifiers and vocabularies. The work done on a record (checking, comparing, predicting and proving it) is the Ectropy service.
